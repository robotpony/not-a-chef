Heart in a frying pan: vector favicon variants

Second favicon pass. The pixel-grid pans and fried eggs (icons.html) read as retro; this pass goes for a brand mark instead: a red heart, emoji-shaped, sitting in a flat top-down skillet. Drawn on a 32×32 grid so the 16px tab icon lands on half-pixel boundaries.

Every colour is a token from STYLE.md except the heart red, which is the palette's red hue (14°) pushed darker and more saturated than the shared 57%/62% formula so it reads as "red heart" and not salmon. See the note at the bottom.

NOTE

The heart red is the one new value. The palette's red at the shared formula, hsl(14 57% 62%) = #D58167, looks like salmon next to a dark pan. The mockups use #C6522F (hsl(14 62% 48%)): same hue, so it doesn't break the "no new hues" rule, but it is a new lightness. A true emoji red (hue ~355°) would be a new hue and is left out on purpose. Variant 06 shows --accent-strong as the heart for comparison.

Dark tabs. A cast-iron (--ink) pan nearly vanishes on a dark tab strip. Variants 01 and 06 are drawn without a background tile, so they need the adaptive treatment in 05 (an SVG favicon can carry its own prefers-color-scheme rule) or a tile like 04.

Shipping. Once one is picked: static/favicon.svg (the adaptive version), plus 16/32 PNGs and a 180px apple-touch-icon.png rendered from the tiled version, wired through layouts/partials/favicons.html so the Blowfish fallback in head.html stops firing.
