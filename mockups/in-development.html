Recipes in development

A recipe here isn't finished when it's written down. It gets cooked, adjusted, argued about, and cooked again, and only after a while does it settle into the version the family makes without thinking. This proposal makes that visible: a published recipe can say, in a friendly way, that it's still changing.

It reuses draft: true instead of adding a new field. A draft now ships to the live site with a banner on its page and a small mark on its card. Removing draft makes it canon, and nothing is shown. The words come from config, so Fugu says one thing and Not a Chef says another.

§1

One flag, two states

Today draft: true means hidden: buildDrafts = false keeps it off the site, and the existing .draft-badge only ever appears in local preview. Under this proposal the same flag means "live, and still changing".

today · draft: true

Hidden draft

Never built. Only you see it, in make preview. Goes away as a state.

→
draft: true

In development

Published. Banner on the page, mark on the card, optional working_on note. Cookable, but expect it to move.

→
no draft key

Canon

The settled version. No banner, no mark. Silence is the signal, so most of the site stays quiet.

!

Cost: no more private drafts. Four pages carry draft: true today, and two are essays (meal-planning-bruces-take, tips-and-tricks-for-cooking-on-the-road) plus a reference page. They'd all go live with the banner.

If something truly needs to stay private, Hugo's build: { render: never, list: never } still hides a page, or it can live outside content/. That's rare enough not to need its own state.

§2

Wording

Fugu ships the neutral pair, In development / Canon. Not a Chef overrides it with something from the kitchen. Pick a row (or a pill in the bar below) and every frame on this page changes to match.

OptionBanner sentenceCard hoverSettled state
→

My pick for Not a Chef: "On the stove". It's concrete, it's a place rather than a judgment, and "still cooking" is exactly the feeling: it's edible now and it isn't done. "Test kitchen" sounds like somebody else's lab, and "Still tinkering" puts the focus on the writer instead of the dish.

The settled word only shows up on the explainer page, since canon recipes carry no mark. "Settled" pairs with the stove. "Canon" stays the Fugu term.

§5

The explainer page

Every banner and popover links here. It's a normal reference page (content/reference/how-recipes-grow.md), so it's edited in Obsidian like everything else. Draft copy below.

Reference

How recipes grow here

None of these recipes started out finished. Each one began as something we cooked once, wrote down roughly, and then changed every time we made it.

Some of them have stopped changing. Others haven't yet, and we'd rather show you those than hide them until they're perfect. A recipe still in progress is usually good to cook. It just hasn't settled.

On the stoveStill changing. Cook it, adjust it, and expect the next version to be a little different. If there's a "working on" note, that's what we're trying next.
✓
SettledThe version we make without looking. No label, because most of the book should read this way.

Change it anyway

Settled doesn't mean finished for you. Every recipe here is a starting point: swap the beans, cut the sugar, write your changes in the margin. That's how these got here.

The settled row shows a check here only. On real pages, canon recipes stay unmarked.

§6

How it would be built

The theme does the generic part. This repo sets the words and the icon.

Frontmatter (per recipe)

draft: true
working_on: Getting them to hold without the egg. Chickpea flour next.   # optional

Fugu defaults (themes/fugu/config / theme params)

[params.development]
  label   = "In development"
  canon   = "Canon"
  message = "This recipe is still changing. Cook it, change it, and expect it to move before it becomes canon."
  hover   = "Published while it's still being worked out. It works, but the next version will be a little different."
  more    = "How recipes grow"
  page    = ""         # explainer page; no link when empty
  icon    = "dot"      # or the name of an icon in assets/icons/

Not a Chef overrides (config/_default/params.toml)
