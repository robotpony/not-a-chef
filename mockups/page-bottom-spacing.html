Page bottom spacing

About runs straight into the footer: its last row of photo markers sits on the footer's top border. Every other page type already ends 40px above the footer, but none of them sets that on purpose. Each one borrows it from whatever block happens to come last. About has no such block, so it gets nothing.

The fix is to make 40px the page's own rule, so it holds no matter what the last block is.

§1

The rule

40px from the last thing on the page to the footer's top border, on every page, at every width. It's the same 40px the home page's sections use between bands (.home-section), and the top of STYLE.md's "section spacing" range, so the bottom of a page reads like the break between two sections, not a new kind of gap.

§2

Measured today

Distance from the last visible text, image or control to the footer, in Chrome at 1280px and 390px (2026-10-07). Where the 40px comes from is the problem: four different rules, by accident.

§4

Build

All site CSS (assets/css/custom.css); no Fugu change.

OptionChangeTrade-off
A · page owns it (recommended)main { padding-bottom: 40px }, and take the bottom space off the four blocks that supply it today (.article-pagination margin, the last .home-section's bottom padding, the listing spacer, the term list margin) so they don't add up to 80px.One rule, and a new page type gets it for free. Touches five rules, so every page type gets measured again before and after; the target is that only About changes.
B · patch AboutGive pages with the reading sidebar and no previous/next links a 40px bottom margin.One rule and no risk elsewhere, but the gap stays borrowed: the next page type without a closing block has the same bug.
i

STYLE.md. Add "page bottom: 40px to the footer" under Spacing & radius when it lands, so it's a rule rather than a coincidence.

§5

Open questions

1

Option A or B? A is the real fix; B is the quick one.

2

40px everywhere, or more on desktop? 40px matches every page today, so it's the no-surprise choice. A larger desktop gap (48–56px) would give long pages more of an ending, but would change every page.
