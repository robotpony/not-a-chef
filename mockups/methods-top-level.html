4 · Decisions
  1. Folder move to content/methods/, so methods get /methods/… URLs and a Methods-only breadcrumb. It needs the Fugu change first (fugu-agent), then the move. Recommended.
  2. Redirects: none needed for /essays/methods/… (never published). Keep or drop the two old Reference redirects (§1)?
  3. The methods page becomes /methods/ (the section's own page) and the method tag page goes back to a plain tag list. Alternative: keep /tags/method/ as the methods page and point the nav there. Recommended: /methods/, so the URL matches the nav.
  4. Nav fit: six items overflow by about 40px at 700px, so anywhere from 680px to about 740px wide (§2). Fixes, smallest first: label it "Food Log" in the nav (drops "The"); trim link padding from 10px to 8px; or move the drawer breakpoint up to 760px. Recommended: "Food Log", since the page title can keep "The".
  5. Nav order: Recipes · Methods · Essays · The Food Log · Reference · About. Alternative: Methods after Essays, beside Reference.
  6. Homepage: A, B, or C. Measured at desktop width below the hero: A is about 365px taller than today, B about 20px shorter, C about 20px taller. My pick is C: it adds methods at today's height and keeps food memories visible as their own list, which B gives up. Essay intros read fine as one line in a list. B is the fallback if the page has to get shorter.
  7. Methods band shape: a blueprint block with its parts inline (the methods page's block, made shorter) beside the techniques as rows. When a second blueprint lands, it takes a second block and the techniques move under them.
