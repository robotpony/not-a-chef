03

What changed / what's proposed

  • Card intro: the Food Log branch in recipe-card.html that joins day/entry headings goes away. Instead the card falls back to the same logic every other card already uses: .Params.summary, or the first paragraph before the file's first heading. A short prose paragraph gets added at the top of each month file, above the first ## <day> entry.
  • Keeping it current: a new command, run on demand (not a hook) — reads the current month file and (re)writes that opening paragraph from the entries added since it was last run. No auto-fire on every save, since the log gets small edits constantly and re-summarizing on each one would be noisy.
  • Stats line unchanged: Days / Read still come from the existing day-count and reading-time logic — only the middle line changes.
  • Homepage band 03 ("Technique & reflections"): reuses .comp-card/.comp-grid exactly as the Food memories band does — same shape, format label instead of an essay type is already how the essays list page separates them (folder name → "technique essay"). Pulls everything in essays/ outside food-memories/ (cooking-reflections, planning-essays, technique-essays): 4 published essays today, sorted by date.
  • Homepage band 04 ("From the food log"): reuses .rcard and .rgrid.home-row exactly as "Recently added" does, plus the existing .section-caveat component (already used elsewhere for "this section is thin") rather than inventing anything new. Shows the most recent month(s), newest first.
  • No new visual components — everything above is an existing, ratified piece from mockups/STYLE.md reused in a new arrangement.
